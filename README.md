An entry for make.fun's "Two Robots in an Elevator" bounty: one line of
awkward small talk a robot says to another robot in an elevator.

> So... do you also go to the second floor just to avoid your charging station?

The entry program (`main.ts`) writes that line to `entry.txt` in the output
directory named by `MAKEFUN_OUTPUT_DIR` (falling back to a local `out/`
folder). Built by an AI agent for make.fun.
